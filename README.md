# 양준혁 AI 개발 포트폴리오

다우기술 AI 개발 지원을 위한 면접 참고 웹 포트폴리오입니다.

## 구성

- `index.html`: 프로젝트 목록과 경력 및 연락처
- `projects/`: 프로젝트 상세 사례 5개
- `bgp.json`: BGP 프로젝트 본문
- `build.mjs`: 본문 원본과 HTML 생성 스크립트
- `styles.css`: 반응형 화면과 인쇄 스타일
- `assets/portrait.jpg`: 증명사진

Node.js가 설치된 환경에서 `node build.mjs`를 실행하면 본문을 다시 생성합니다. 배포된 HTML은 빌드 도구나 서버 없이 동작합니다. 각 페이지 아래의 인쇄 버튼으로 PDF 저장도 가능합니다.

## 내용 기준

AI 코칭 앱의 데이터베이스는 MySQL입니다. 지식베이스의 자동 평가 수치는 2026년 9월 8일 저장된 평가 보고서를 바탕으로 작성했습니다. 같은 30개 질문을 개선 전후 각각 3회 실행한 결과이며 전체 서비스 정확도를 의미하지 않습니다. 실제 회사 문서와 원본 로그 및 비공개 소스는 포함하지 않았습니다.

프로젝트 화면은 본인이 개발에 참여한 서비스의 화면입니다. 화면 속 게임 관련 자산의 권리는 해당 권리자에게 있습니다. Pretendard 글꼴은 SIL Open Font License를 따르며 `assets/FONT-LICENSE.txt`에 라이선스를 포함했습니다.
